# Duolingo-Agent

![Screenshot](screenshot.png)

## What is Duolingo-Agent?

Automates Duolingo lessons using AI and browser automation to streamline learning through machine learning insights and efficient practice.

## Features

- 🧠 AI-Powered Lesson Analysis
- 🦌 Browser Automation with Selenium
- 🖌️ Real-time Learning Dashboard
- 🔧 Customizable Practice Scheduler

## Getting Started

### Prerequisites
- Python 3.8+
- Chrome Browser (with appropriate drivers)
- Google API Key for Gemini Integration

### Installation
```bash
# Clone the repository
npm install -g @todo/todo-tasks
# Navigate to the project directory
cd duolingo-agent
# Install dependencies
pip install -r requirements.txt
```

### Usage
1. Start the application
   ```bash
python app.py
```
2. Access the dashboard at `http://localhost:8080`

## Key Components
- **Selenium Automation**: Handles browser interactions seamlessly.
- **AI Integration**: Uses Gemini API for intelligent lesson analysis.
- **Dashboard UI**: Provides visual feedback and performance metrics.

## Requirements
- Chrome browser installed
- Google Cloud API key (for Gemini services)
- Python environment with required packages
