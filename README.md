# Duolingo-Agent

Automates Duolingo lessons using AI and browser automation to streamline learning through machine learning insights and efficient practice.

## Features
- 🧠 AI-Powered Lesson Analysis 
- 🦌 Browser Automation with Selenium
- ⚡ Fast Execution Mode

## Getting Started

### Prerequisites
- Python 3.8+
- Chrome Browser
- Google Gemini API Key

### Installation
```bash
pip install selenium webdriver-manager google-genai
```

### Usage
Run the script directly from your terminal:
```bash
python Duolingo_Agent.py
```
You will be prompted to enter your Gemini API key in the terminal. The bot will launch Chrome, wait for you to log in to Duolingo, and then automatically start and solve lessons at high speed.
